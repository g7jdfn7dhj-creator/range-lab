# Credits / Лицензии

## 3D-модели техники (v3, пакет 1: Т-72Б, Т-90М, Leopard 2A6, M1A2 SEPv3)
Все модели — **процедурные** (three.js, `models-v3.js`, `models-v3-tanks.js`), собственный код проекта. Сторонних 3D-ассетов, чужих мешей и выдранных из игр моделей нет.
Размеры и пропорции сняты по открытым ТТХ и чертежам/фотографиям, которые использовались только как справочный материал для измерения силуэтов (в проект не включены):
- чертежи The-Blueprints.com (превью 1:50, только для замеров);
- фотографии Wikimedia Commons (CC BY / CC BY-SA / PD) — только как справка о внешнем виде.

Остальные вкладки (текстуры, шрифты и т. д.) — как раньше.
